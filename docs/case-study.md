# Green Lens · 产品案例

## 问题与目标

消费品牌的 ESG 信息散落在报道与报告中。用户需要的第一步通常是“值得关注什么、去哪里核实”，而不是复杂的专业评级模型。原型用品牌搜索验证这条信息获取路径。

## 三个产品取舍

| 决策 | 原因 | 代价与后续验证 |
| --- | --- | --- |
| 品牌搜索作为入口 | 贴近用户已有的消费对象 | 品牌别名、同名和子品牌需要消歧 |
| 三维分析加综合分 | 在阅读速度和信息结构之间取平衡 | 数字可能制造过度确定感，应增加置信度 |
| 关键事实关联来源 | 让用户能继续核实 | 来源关联仍需逐条校验，不能只依赖模型编号 |

## 案例：从结论回到证据

**演示任务：** 搜索一个品牌，选择一条负面关键事实，阅读其对应报道。此任务用于体验流程，不预设品牌表现，也不提供固定真实评分。

检查顺序：品牌实体是否一致 → 报道日期是否明确 → 摘要是否遗漏重要条件 → 来源是否支持关键事实 → 评分是否与事实的严重程度相称。

**计算示例，仅用于说明规则：** 假设 E=80、S=60、G=70，则总分为 `round(80×0.3 + 60×0.4 + 70×0.3)=69`，评级为 Meh。此处没有对应任何品牌或模型运行结果。

## 实现与规划

- **已实现：** Tavily 搜索、来源编号、模型 JSON 分析、固定权重计算、维度与来源展示。
- **后续方案：** 基准校准表、结构化事件评分、置信度、社区反馈、榜单与报告。
- **尚未证实：** 专业评级一致性、消费者决策改善、留存与商业化。

## 如何评估

建立覆盖同名品牌、无相关新闻、正负事件混合、重复报道和来源日期缺失的人工标注样本。逐项检查品牌相关性、事实支持率、引用对应率和评分计算正确性；记录重复查询差异、耗时与成本。

用户验证关注能否复述评分依据、能否定位来源，以及是否能识别证据不足。所有指标在测量前均是评估计划。
